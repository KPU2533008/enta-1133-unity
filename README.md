# enta-1133-unity (untitled dungeon game)

## HOW TO PLAY
- Use WASD to move around and traverse a procedurally generated dungeon
- Use the mouse to look around and re-orient yourself
- Rooms with red lights are combat rooms, where you will fight enemies in a turn-based combat encounter
- Some rooms will contain treasure chests with loot! Press E while near them to collect their loot
- If you run out of HP, the game will end
- Clear all the combat rooms to win the game!
